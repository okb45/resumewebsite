Amiga Navigation

This project began with the deployment of an Amiga robot equipped with Farm-ng navigation brains. I developed a program that generated custom track information from recorded waypoints, enabling the robot to autonomously follow precise paths. Using this system, the robot was driven across a field to create a grid of lines running north–south and east–west. At each intersection, posts were installed, which together laid out the framework for a new four-acre vineyard.

Following the vineyard-plotting phase, the navigation system evolved into a pure pursuit controller running on an NVIDIA Jetson Xavier. While the new electrical system for this platform was designed externally, I was responsible for its assembly and integration, as well as designing and 3D printing a custom mounting system for the Jetson-based navigation hardware.

The broader goal of this work was to transform the robot into a versatile agricultural research tool carrier. Potential applications include mounting NDVI sensors for crop health monitoring, integrating sucker-sprayer mechanisms, assisting in vineyard establishment, or performing tasks such as mowing and under-vine maintenance. This adaptability highlights the robot’s potential to serve as a scalable and flexible platform for future agricultural innovations.
